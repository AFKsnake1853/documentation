---
title: "Session roles"
description: "The roles staff sign up for on a session."
icon: "user"
iconType: "solid"
---

Staff sign up for the roles a session type uses. A role can have a limit on how many people take it.

Set up roles in **Settings › Sessions › Roles**. Put them in groups, then choose which groups each session type uses.

Assigning someone else to a role needs the **Assign session roles** permission.
