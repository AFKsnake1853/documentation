---
title: "Session servers"
description: "Servers on a session, each with a Host and a Co-Host."
icon: "server"
iconType: "solid"
---

Each session has servers. Each server has a **Host** and a **Co-Host**, and a private server code for staff to join with.

Adding and editing servers needs the **Manage session servers** permission. Hosting needs **Host sessions**, and co-hosting needs **Co-host sessions**.
