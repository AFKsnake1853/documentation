Every member of a workspace has a role. Manage roles in **Settings › Roles**: select a role on the left to see and change its permissions.

## Workspace Admin

The **Workspace Admin** permission includes every other permission, and is the only way into **Settings**. The workspace owner always has it.

## Module permissions

Each module adds its own permissions, such as:

| Module | Permissions |
|---|---|
| Staff | View staff, Manage staff, View logbooks, View time off, Approve time off, Manage team views |
| Activity | View activity, Manage activity, View time off, Approve time off |
| Sessions | Manage sessions, Host sessions, Co-host sessions, Assign session roles, Manage session servers |
| Assignments | View assignments, Manage assignments |
| Knowledge | View knowledge, Manage knowledge |

Someone without a module's view permission doesn't see that module in their sidebar.
