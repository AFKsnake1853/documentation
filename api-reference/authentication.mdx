<Note>
  Authentication is required for **all** API endpoints. Your API key should be kept secure and never exposed in client-side code.
</Note>

## How to Authenticate

All requests to the Kith API (`https://api.lumonol.co.uk`) must include two essential pieces of information:

1. **Workspace ID**: Provided as a query parameter (`?workspace_id=YOUR_WORKSPACE_ID`) or in the JSON body.
2. **API Key**: Provided as a Bearer token in the `Authorization` header.

### Example Request

```bash
curl -X GET "https://api.lumonol.co.uk/staff?workspace_id=12345-abcde" \
  -H "Authorization: Bearer kith_workspace_key_..." \
  -H "Content-Type: application/json"
```

<Warning>
  If your Workspace ID or API Key is missing or invalid, the API will reject your request with a `401 Unauthorized` response.
</Warning>

## Generating API Keys

API Keys are generated from your Dashboard under **Workspace Settings > Developer API**. 
Each key is strictly scoped to its specific Workspace. If you suspect an API key has been compromised, you can revoke and regenerate it immediately from the dashboard.
