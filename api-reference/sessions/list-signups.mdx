---
title: "Retrieve Session Signups"
api: "GET https://api.lumonol.co.uk/sessions/{sessionId}/signups"
description: "Fetch everyone who has claimed or been assigned a role in a specific session."
---

<ParamField path="sessionId" type="string" required>
  The unique ID of the session.
</ParamField>

<ParamField query="workspace_id" type="string" required>
  Your unique Workspace ID.
</ParamField>

<RequestExample>
```bash cURL
curl -X GET "https://api.lumonol.co.uk/sessions/uuid-of-session/signups?workspace_id=YOUR_WORKSPACE_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</RequestExample>
