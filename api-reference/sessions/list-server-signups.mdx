---
title: "Retrieve Server Signups"
api: "GET https://api.lumonol.co.uk/sessions/servers/{serverId}/signups"
description: "Fetch everyone assigned to a role inside a specific session server, including their Roblox IDs and role details."
---

<ParamField path="serverId" type="string" required>
  The unique ID of the server record.
</ParamField>

<ParamField query="workspace_id" type="string" required>
  Your unique Workspace ID.
</ParamField>

<RequestExample>
```bash cURL
curl -X GET "https://api.lumonol.co.uk/sessions/servers/uuid-of-server/signups?workspace_id=YOUR_WORKSPACE_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</RequestExample>
